# Archived ADRs

Decision records that no longer describe the current system: superseded, withdrawn, or replaced by a newer decision.

`docs/adr/` holds current decisions only. An ADR moves here when a later ADR replaces it; the replacement records why, and links back to the archived record for context. Kept for history, not for guidance — do not treat anything in this folder as current.

Numbering is not reused: the next ADR continues from the highest number in either folder.
